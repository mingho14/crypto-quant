# Crypto Quant Research

A learning-by-doing repository for systematic crypto quantitative trading research.

## Research workflow

Idea → Hypothesis → Data → Research → Signal → Backtest → Validation → Risk Management → Paper Trading → Small Live Trading → Monitoring → Iteration

## Repository structure

- `research/` — experiment specs, hypotheses, assumptions, results, and research logs
- `data/raw/` — local raw market data (ignored by Git)
- `data/processed/` — local processed datasets (ignored by Git)
- `notebooks/` — exploratory analysis and experiments
- `src/` — reusable research/backtesting code
- `tests/` — tests and sanity checks
